# plain-tickets v0.2.0

A ground-up rewrite of the CLI. It is not a diff against v0.1.0: the TUI
kanban board is gone, and ticket files and IDs use a new format.

## Highlights

- **Ticket format**: markdown with YAML front matter; IDs are random u64
  values in base36; timestamps are ISO 8601 with milliseconds.
- **Commands**: `init`, `new`, `edit`, `show`, `list`, `set`, `tag`, `untag`,
  `block`, `unblock`, `note`, `archive`, `unarchive`.
- **Pretty output**: `list` and `show` render as aligned, coloured tables and
  header blocks on a terminal, with icons for common types and statuses.
  `--format` picks the presenter explicitly.
- **Short IDs**: commands accept any unique ID prefix; the non-unique part is
  greyed out in pretty output.
- **Archiving**: several tickets at once, or all rejected ones.
- **New tickets from STDIN**: `tickets new "..." -m -`.
- **`--version`** shows the short git SHA.

## Robustness

- Ticket files are replaced atomically; `edit` uses a private temp directory.
- Listing skips stray files and warns about corrupt tickets.
- Tickets list in creation order even when created in the same millisecond.
- Builds and passes its tests on Linux, macOS and Windows.
