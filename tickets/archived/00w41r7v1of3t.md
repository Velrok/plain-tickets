## Problem

`run()` in `cli/handlers.rs` ends with `_ => Err("not implemented yet")`. It only covers `Init` today, but a future `Command` variant would compile and fail at runtime.

## Acceptance

- Match `Command::Init` explicitly.
- Remove the wildcard so the compiler enforces exhaustiveness.

Removed the wildcard; Command::Init is an explicit unreachable! arm since main handles init first. Compiler check only, no behavioural test possible.
