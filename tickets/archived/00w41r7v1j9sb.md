## Problem

`edit_text` (`cli/handlers.rs`) writes `tickets-<id>-<pid>.md` in the shared temp dir. The name is guessable, so another local user could pre-create it or plant a symlink.

## Acceptance

- Create the file with `create_new` in a private (mode 0700) temp directory, or under a random name.
- Remove it afterwards.
- Test that an existing file at the old name is not followed or overwritten.

Fixed: edit_text now makes a random-named 0700 dir under the temp dir (DirBuilder, fails if it exists), opens the file inside with create_new, and removes the dir afterwards. The 'old name pre-existing' test was not written: the name is no longer predictable (random u64), so tests check the 0700 private dir and cleanup instead.
