Repro: new A; new B -b A; set A --status done; archive A; note B hi => 'ticket A is archived'.

Cause: save_revision -> ensure_exist -> store::require only looks at active tickets (handlers.rs, store.rs).

Acceptance: ticket with an archived (done/rejected) blocker or parent can still be modified. Use store::find or only check newly added IDs. Add an integration test.
