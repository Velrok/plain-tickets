## Problem

Once a ticket's blocker or parent is archived, the blocked ticket can no longer be changed.

## Repro

1. `tickets new A`, then `tickets new B -b <A>`
1. `tickets set <A> --status done`, then `tickets archive <A>`
1. `tickets note <B> hi` fails with `ticket <A> is archived`

## Cause

`save_revision` calls `ensure_exist`, which uses `store::require`. That only looks at active tickets (`cli/handlers.rs`, `domain/store.rs`).

## Acceptance

- A ticket whose blocker or parent is archived can still be modified.
- Existence checks use `store::find`, or only check newly added IDs.
- Integration test for the repro above.
