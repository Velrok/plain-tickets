## Problem

`archive` takes one ID. The old implementation in `../main` takes several and can bulk-archive rejected tickets.

## Acceptance

- `tickets archive <id>...` takes one or more IDs.
- `tickets archive --all-rejected` archives every rejected active ticket; it conflicts with IDs.
- All IDs are validated before any ticket moves, so a bad ID changes nothing.
- Integration tests in `tests/archive.rs`; README updated.
