## Problem

`tickets new -m` only takes literal text, or opens `$EDITOR` on a terminal. The old implementation in `../main` had `--body -` to read STDIN.

## Acceptance

- `tickets new "Title" -m -` reads the whole body from STDIN.
- Clear error if STDIN is a terminal.
- Integration test; README and `--help` text updated.
