handlers.rs edit_text writes tickets-<id>-<pid>.md in std::env::temp_dir(). The name is guessable, so another local user could pre-create it or plant a symlink there.

Acceptance: create the file with create_new in a private (mode 0700) temp directory, or a random name, and remove it afterwards. Test that an existing file at the old name is not followed or overwritten.
